# VenueNow Live

[Öppna konsertbutiken](https://nurism.github.io/VenueNow-Live/)

Sök konserter, lägg biljetter i kundvagnen och prova en demobokning. Evenemangen är fiktiva. Biljetter sparas lokalt i webbläsaren.

För att öppna sidan lokalt, ladda ner projektet, packa upp och öppna index.html. Inga installationer krävs.
